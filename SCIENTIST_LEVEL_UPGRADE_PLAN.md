# Scientist-Level Upgrade Plan

## Positioning

This project should be presented as an **Agentic ML Decision Support System for Singapore MNC Risk and Strategy**.

That sounds stronger than "risk dashboard" because it combines:

- business risk analytics
- machine learning-style segmentation
- stress testing
- explainability
- policy-aware strategy recommendation
- AI-agent workflow

## Best Architecture

```text
Data layer
  -> Industry risk dataset
  -> Singapore policy context
  -> Future live macro/news data

Feature layer
  -> Cost pressure
  -> Talent risk
  -> Competition/growth
  -> Compliance risk
  -> Global strategy risk
  -> Automation readiness
  -> Regional expansion fit

ML layer
  -> Weighted risk scoring
  -> K-means strategic segmentation
  -> Monte Carlo stress testing
  -> Risk contribution explainability

Agent layer
  -> Retrieve profile
  -> Calculate risk
  -> Run stress simulation
  -> Add policy context
  -> Generate board recommendation

Interface layer
  -> Browser dashboard
  -> Optional Streamlit dashboard
  -> Report and viva explanation
```

## Viva Pitch

This project is not a static business report. It is a decision-support system. The agent first reads an industry profile, calculates risk, runs stress simulations, explains top risk drivers, adds current Singapore policy context, and produces a board-level recommendation. The model is transparent enough for business users and technical enough to demonstrate machine learning thinking.
